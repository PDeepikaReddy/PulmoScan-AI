          About this project

          PulmoScan AI is an educational deep-learning project. It uses transfer learning on the Tuberculosis (TB) Chest X-ray Database from Kaggle to distinguish normal chest X-rays from those showing tuberculosis. The model, web interface, and recommendations are built for learning and demonstration — they do not constitute medical advice or a diagnosis. Always consult a qualified clinician.
